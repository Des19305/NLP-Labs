# LAB 03 — Word Embeddings

## Dữ liệu
Notebook `word_embedding.ipynb` sử dụng **NLTK Brown Corpus**

## Chạy
1. Chạy các cell từ trên xuống.
2. Nếu thiếu thư viện, chạy cell `%pip install nltk gensim pandas numpy`.
3. Ghi lại kết quả thực tế; không tự điền các điểm similarity/analogy chưa chạy.

## File
- `cooccurrence.py`: triển khai co-occurrence matrix từ đầu cho phần core implementation.
- `word_embedding.ipynb`: thí nghiệm Word2Vec với Brown Corpus, gồm phần 17–18, 19, 20, 21 và thử nghiệm analogy.
- `results.csv`: mẫu CSV để ghi kết quả.
- `calculations.pdf`, `prediction.pdf`: viết tay và scan
-  `error_analysis.md`, `reflection.md`: hoàn thiện theo yêu cầu của bài lab.
