# NLP Lab 05 — Sequence Models: RNN, LSTM and GRU

## Files
- `sequence_classification.ipynb`: practical experiments and plots.
- `rnn_cell.py`: manually implemented `SimpleRNNCell`.
- `results.csv`: generated by running the notebook.
- `learning_curves.png`, `confusion_matrix.png`: generated by the notebook.
- Other experiment plots are also saved by the notebook.

## Environment
Recommended Python 3.10–3.12. Create and activate a virtual environment, then install:

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
# source .venv/bin/activate
python -m pip install --upgrade pip
pip install tensorflow numpy pandas scikit-learn matplotlib seaborn jupyter
jupyter notebook
```

The notebook downloads the IMDb dataset using `tensorflow.keras.datasets.imdb` on first run. Internet access is needed the first time. It uses a 20,000-word indexed vocabulary from the Keras IMDb dataset, so the dataset is already tokenized/indexed rather than original raw review text.

## Important
- Run cells from top to bottom.
- Training time and scores depend on hardware, TensorFlow version, and random variation. Do not copy expected numbers; use your own results.
- The notebook saves `results.csv`, `learning_curves.png`, `confusion_matrix.png`, `sequence_length_histogram.png`, `max_length_vs_f1.png`, and `max_length_vs_training_time.png`.
- Some experiments can take a while, especially LSTM/GRU and the max-length comparison. Start with fewer epochs for debugging, then run the required settings consistently.
- Do not submit AI-generated interpretations as your own. Use the prompts marked **YOUR COMMENT / ANSWER REQUIRED** to write your own analysis in `prediction.pdf`, `calculations.pdf`, `error_analysis.md`, and `reflection.md`.
